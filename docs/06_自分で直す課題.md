# 06 自分で直す課題

制作者が自分で(Claude Code を使って)直す課題。直し方はここには書かない。

## 課題1 予定日を空欄にした記録で、前の来店予定が一覧から消える

### 何が起きるか(再現手順)

1. 見本データを入れる(`npm run db:seed`)。画面上部で「今のスタッフ」を選ぶ
2. 新規のお客様で記録する。用件・温度感を選び、**次回来店予定に1週間後の日付**を入れて保存する
3. 「今日」の画面の「今週のこのあとの予定」(週をまたぐ場合は翌週以降の画面)で、そのお客様が予定として出ることを確かめる
4. 同じお客様を開き、「このお客様の記録を残す」から、もう1件記録する。**次回来店予定は空欄のまま**保存する
5. 「今日」の画面に戻ると、手順2で入れた来店予定が一覧から消えている

今の作りは、お客様ごとに「いちばん新しい記録」の次回来店予定だけを見ている。統合テスト「その後に来店して新しい記録ができたら、古い予定は一覧から消える」は、この動きを正しいものとして確かめている。

### なぜ困るか(売り場の場面)

- 月曜に来たお客様と「土曜に書類を持ってまた来ます」と約束し、予定日を土曜で記録した
- 水曜に同じお客様が、別の用事(ケースを買いに、など)で立ち寄った。対応したイベントスタッフは、土曜の約束を知らないまま、予定日を空欄で記録した
- 土曜の朝、「今日の来店予定」にそのお客様が出ない。書類の確認や在庫の取り置きなど、来店前にしておく準備がされない
- お客様は約束どおり来たのに、スタッフは知らない。「前回だれに何を聞いたか分からない」という、この作品が解きたかった困りごとがまた起きる

## 課題2 「済み」ボタンを押した人と、画面に出ている担当者が食い違うことがある

### 何が起きるか(再現手順)

1. 見本データを入れる(`npm run db:seed`)。画面上部で「今のスタッフ」を高橋 恵にする
2. 「今日」の画面か、お客様カードを開く。「終わっていない『次にやること』」に「済み」ボタンが出ている。この画面の上部は高橋 恵のまま
3. 同じブラウザの別のタブを開き、「今のスタッフ」を森田 陽菜に替える
4. 最初のタブに戻り、画面上部が高橋 恵のまま出ている状態で「済み」を押す
5. お客様カードの記録を見ると、その「次にやること」は**森田 陽菜が済ませたこと**になっている

記録を保存するときは、画面に出ていた担当者と保存する人を突き合わせて、違えば断るようにした(03「迷った所 12」)。「済み」ボタンには、まだその突き合わせが無い。

### なぜ困るか(売り場の場面)

- 高橋さんが「入荷の連絡、済ませました」のつもりで押したのに、記録上は森田さんが済ませたことになる
- 後日お客様から「連絡もらってないよ」と言われたとき、記録を見て森田さんに聞きに行くが、森田さんは何も知らない。本当に連絡したのが誰か、たどれなくなる
- この作品が守りたかった「誰が案内したか(誰が済ませたか)必ず残る」が、正しくない名前で残ってしまう
