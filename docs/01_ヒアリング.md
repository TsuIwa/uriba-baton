# 01 ヒアリング(2026-10-06)

聞いた相手:携帯売り場で14年働いている現場の人(制作者本人)。
聞いたこと4つと、返ってきた言葉(原文)。

| 問い | 答え(原文) |
|---|---|
| 1. 問い合わせや引き継ぎで困ったことは? | お客様が前回だれに何を聞いたか分からない、週末イベントスタッフが案内していて、さっくりした内容しか案内していない上に誰が案内しているかわからないことがある、最初から説明をしないといけない |
| 2. 今は何で記録している? | 紙のメモ |
| 3. 一番困るのは? | お客様と臨機応変に対応することが苦手なスタッフ |
| 4. これができたら助かる、を1つだけ | 時間をほぼ取らない引き継ぎツール |

## 聞いた話から読み取ったこと
- 困っているのは**2回目に来たお客様**と**それを受けるスタッフ**の両方。お客様は同じ説明をもう一度聞かされ、スタッフは何を話せばいいか分からない
- 原因は3つ:①記録が紙で、探せない・残らない ②**誰が**案内したかが残らない ③**どこまで**案内したかが「さっくり」で分からない
- 臨機応変が苦手なスタッフほど、前回の記録が無いと止まる → 記録は「次に何を話せばいいか」まで見せる必要がある
- 週末のイベントスタッフは忙しい → 書く手間が少しでも増えると使われない。**入力はタップ中心で30秒以内**を目標にする
